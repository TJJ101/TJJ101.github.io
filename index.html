Lightweight Image-Space Deformation

C++, GLSL, OpenGL, CMake, ImGui

A computer graphics research project on simulating surface bending, compression and wrinkles in a fragment shader, without changing the mesh.

Research poster submitted to Pacific Graphics 2026

Lightweight Image-Space Deformation is a computer graphics research project exploring how convincing surface deformation can be simulated without modifying the underlying mesh geometry. The project investigates an alternative to traditional geometry-based deformation by using height information and fragment-shader techniques to create the visual appearance of surfaces bending, compressing, and forming wrinkles.

The implementation primarily uses a height-guided parallax approach. Rather than physically moving vertices or introducing a skeletal rig, the fragment shader perturbs texture coordinates based on height information to simulate changes in surface depth. This allows deformation effects to be generated at the image level while keeping the original mesh intact, reducing the need for expensive geometry updates.

The system is designed to support different materials and deformation characteristics. Various models and height maps are used to experiment with how surfaces respond to interaction, including skin-like, gel-like, and softer materials. Particular attention is given to producing convincing wrinkles and folds, where the visual response should reflect the direction and intensity of the applied deformation.

An additional aspect of the project is its exploration of haptic interaction. A physical input device, incorporating a pincer-style mechanism, is used to provide a tangible way of interacting with the simulated surface. The interaction connects physical input with the visual deformation response, allowing the project to explore how image-space techniques can be extended beyond purely visual applications.

The research poster has been submitted to Pacific Graphics 2026.

Get Me Out of Hell

C++, GLSL, OpenGL ES 3.0, Android Studio

A 2D roguelite where terrain, materials and hazards shape every decision. Built on a custom framework for Windows and Android.

Selected for a public showcase at SIT Artistry 2026

Get Me Out of Hell is a 2D roguelite developed around the idea of navigating a dangerous underground environment where the terrain and surrounding materials play an active role in gameplay. Instead of treating the environment as a static backdrop, the game explores how material behaviour and environmental hazards can influence the player’s decisions and create emergent situations.

A key part of the experience is the interaction between different environmental materials. Materials can move, accumulate, and react to their surroundings, meaning that changes to the terrain can affect how the player navigates an area. Environmental hazards such as heat, toxic substances, and liquid materials introduce additional challenges, requiring players to consider not only where they move but also how their surroundings may change over time.

The project was developed in C++ using OpenGL ES 3.0, with a custom framework supporting the game’s rendering and gameplay systems. Working with a lower-level graphics API provided experience with the underlying processes involved in building a game, rather than relying entirely on an existing game engine. The project also involved adapting the implementation for both Windows and Android, introducing the additional considerations of cross-platform development.

Beyond its gameplay, the project provided an opportunity to explore the relationship between simulation and game design: how environmental systems can create unpredictable interactions, and how those interactions can become meaningful gameplay challenges.

The game was selected for a public showcase at SIT Artistry 2026.

Dwarf Mayhem

C++, Alpha Engine, Cellular Automata

A Noita-inspired 2D game where a cellular-automata material simulation drives destructible terrain.

Dwarf Mayhem is a Noita-inspired 2D game that explores simulation-driven gameplay through cellular automata and destructible environments. The central idea is to make the world itself an active part of the gameplay, where materials can interact dynamically instead of remaining fixed within a predefined level.

The project uses cellular automata to represent and simulate material behaviour across the game environment. Rather than relying solely on manually scripted interactions, the simulation allows individual material elements to update according to their surrounding conditions. This creates the foundation for dynamic terrain and material interactions, where the state of the environment can change as the player interacts with it.

Destructible terrain is an important part of the experience. The environment is not simply a collection of static obstacles; it can be altered during gameplay, allowing players to affect the world around them. This introduces opportunities for emergent interactions and makes the simulation an important component of the overall game experience.

Developed in C++ using the Alpha Engine, Dwarf Mayhem provided an opportunity to explore the implementation of simulation-based systems within a 2D game. In particular, it involved working with cellular automata as a foundation for representing dynamic materials and connecting those systems to the gameplay experience.
